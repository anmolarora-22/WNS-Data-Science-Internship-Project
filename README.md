# WNS Data Science Internship Project

## About the Project
This repository contains work completed during my Data Science Internship at WNS, focused on consumer preference analysis using R.

## Project Work
- Exploratory Data Analysis (EDA)
- Data cleaning and missing-value imputation
- Frequency analysis and histograms
- Correlation analysis
- Exploratory Factor Analysis (EFA)
- Factor interpretation and naming
- Business insights from consumer preference data

## Tools & Technologies
- R
- RStudio
- Excel
- GitHub

## Project Files
- `EDA.R` — Exploratory Data Analysis
- `EFA.R` — Exploratory Factor Analysis
- `CFA.R` — Confirmatory Factor Analysis
- `PROJECT` — Deck
- `Factor Analysis Research` — Research
- `Combined_Report.xlsx` — Consolidated analysis report

## Objective
To identify meaningful patterns in consumer preferences and translate statistical findings into actionable business insights.
